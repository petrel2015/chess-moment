# Chess Moment Roadmap

## M1：JSON 内容框架（已完成）

- 五篇五步课程。
- 自动首页与历史列表。
- 确定性校验、测试和 GitHub Pages workflow。
- 保留现有手机棋盘交互与即时讲解。

## M2：课程质量（已完成）

- 规则引擎升级：王车易位、兵升变（UCI 5 字符走法）、吃过路兵，抽取为 `assets/chess-engine.mjs` 并用纯 Node 单元测试覆盖。
- 为每一步增加候选着、偏离目标但合理的分支（`step.alternatives`，命中时讲解但不计进度）。
- 引入课程标签（`tags`）与先修关系（`prerequisites`，校验器防死链），archive 卡片与文章页展示。
- 回归测试：规则引擎单元测试 + 字段校验测试，CI 自动覆盖。

## M3：学习路径

- 战术、子力交换、开局、局面棋、残局、防守六条路径。
- 用户完成状态、本周连续学习和错题重做。
- 根据错误类型推荐下一课，而不是只按日期浏览。

## M4：引擎与教练

- Web Worker 中运行 Stockfish，提供确定性局面评估。
- 后端代理接入可替换大模型，结合 FEN、课程目标、推荐着和用户问题回答。
- 保存常见追问，反向改进课程 JSON。

## M5：Hermes 自动化

- Hermes 按选题池生成草稿 JSON。
- CI 自动校验并生成手机预览。
- Hermes 只在全部检查通过后创建发布提交。
- 每次发布输出课程数、成功/失败、失败字段和估算成本。
