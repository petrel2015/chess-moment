# 每日首页与归档（Daily Homepage and Archive）

## 概述

首页不需要手工维护：构建时按「今天」的月日自动选择要展示的课程，其余课程自动生成归档卡片。作者只新增课程 JSON，首页与归档永远自动正确。

![移动端布局](../../img/mobile-layout.webp)

## 背景

早期版本首页是固定的最新一期。当课程数量增长后出现两个问题：读者找不到旧课；「每天推送」的语义要求首页在「今天有课」与「今天没课」时都表现合理。

## 问题

1. 「今天该展示哪一期」不应依赖人工编辑 HTML。
2. 旧课程需要可发现、可串联（标签、先修关系）。
3. 归档卡片信息（日期、分类、步数）必须与课程数据保持一致，不能手工复制。

## 目标

- 首页展示 `publishedAt` 的月日与今天匹配的课程；未命中时展示最近一期（跨年亦然）。
- 归档自动排除当前首页课程，避免重复。
- 卡片展示日期、报别（早报/晚报）、标题、摘要、分类与步数，全部来自课程数据。
- 支持 `tags` 标签与 `prerequisites` 先修链接（校验器防死链）。

## 不解决的问题

- 不做日历视图、专题合集或搜索。
- 不做「已读/未读」状态（无用户系统）。
- 不按用户水平个性化推荐。

## 解决方案概述

选择逻辑在 `scripts/content-lib.mjs` 的 `pickHomepageLesson`（纯函数，可测）：

- 先取 `publishedAt` 月日等于今天的课程（不看年份，便于跨年复用）；
- 无匹配时取最近一期。

`build-site.mjs` 渲染每期时把其余课程渲染成归档卡片；先修 `prerequisites` slug 数组在渲染期解析成本地链接，标题按当前语言本地化。测试/CI 可用 `CHESS_HOME_DATE` 环境变量固定「今天」，使构建可复现。

2026-08-11 起（`2af3056`），课程页与页脚加入「反馈问题」按钮：构造 mailto 链接，自动附上课程 ID、当前 FEN 与走子进度，读者报告问题时无需截图描述局面。

## 兼容性与历史影响

增量功能。归档由「最新一期置顶」改为「今日优先 + 最近兜底」，对旧 URL 无影响（每期永久保留 `/<slug>.html`）。无数据迁移。

## 数据与隐私影响

反馈按钮打开本地邮件客户端（用户主动确认后才发送），不自动上报任何数据。

## 当前限制

- 同一天多篇课程时取其一（按排序），不做早/晚报分栏。
- 归档无分页——当前课程量（6 期）远未触及。
