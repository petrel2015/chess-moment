# AI 教练（AI Coach）

## 概述

「问教练」让读者用自然语言追问当前局面：教练用页面语言回答，被系统提示约束为只讲思路、规则与记法，不透露本题答案。默认开箱即用（站点内嵌 OpenRouter 免费模型 Key），可自带 Key 换平台，全部 AI 路径失败时退回预制答案。

![AI 教练设置](../../img/coach-settings.webp)

## 背景

M4 路线（引擎与教练）里原计划接大模型。2026-08-12 第一版通过 Cloudflare Worker 代理智谱 GLM-4-Flash 实现——但要求读者「开箱即用」与维护者「零服务器」之间，Worker 仍是额外部署。随后 OpenRouter 被发现其 API 返回 CORS 头、允许浏览器直连，且有大量 `:free` 模型，使得「不部署任何服务端」成为可能。

## 问题

1. 读者的疑问是长尾的：预制问答覆盖不了「如果我先走车呢？」这类具体追问。
2. 大多数 AI API 不允许浏览器直连（无 CORS 头），传统方案需要服务端代理。
3. 教练若直接报出标准答案，会毁掉「自己想明白」的核心体验。

## 目标

- 访客零操作即可获得真 AI 回答。
- 教练回答跟随页面语言（中/英），150 字以内，一次讲清一个点。
- 硬约束不给出当前题目的标准走法序列。
- 任何 AI 不可用时自动降级，读者永远能拿到一个有用回应。
- 读者可选自带 Key（OpenRouter / DeepSeek / 智谱 GLM），Key 只存本地。

## 不解决的问题

- 不做账号化、计费或用量管理。
- 不承诺 AI 可用性（免费模型无 SLA）。
- 不做对话记忆（每次提问独立，附带局面上下文）。
- 不让 AI 判定走法合法性——那是确定性规则引擎的职责。

## 解决方案概述

`assets/coach-ai.mjs` 是纯逻辑层（可被 Node 测试），`app.js` 负责编排与 UI。降级链（高到低）：

1. **用户配置的平台 + Key**（localStorage），OpenAI 兼容请求直发所选平台；
2. **内嵌 OpenRouter Key**（XOR + Base64 混淆存储，仅免费模型）：按 `OPENROUTER_MODELS` 模型链「主模型重试 → 备用模型降级」，并把降级原因展示给读者；
3. **Cloudflare Worker 代理**（仅当构建期注入 `CHESS_COACH_WORKER_URL`，当前为未配置）；
4. **免 Key 第三方中转**（Pollinations，实验性）；
5. **预制答案**：`defaultAnswer` 与快捷问答（`quick`），由课程作者预写。

系统提示词（中英双语两份）要求：结合 FEN 讲解规则/记法/思路；严禁说出「正确走法是 XX」；非当前局面的问题正常回答。每次请求附带题目标题、目标、起始/当前 FEN 与进度。超时 15 秒。

## 用户体验

- 快捷问题按钮（每题 3–4 个预设疑问）一键填入并回答。
- 回答区标注来源：「真 AI」或「预设参考」（降级时）。
- 「AI 设置」面板可随时切换平台/Key 或清空恢复默认。

## 兼容性与历史影响

- 2026-08-14 曾随内嵌 Key 上线移除了 AI 设置面板，随后同日（`ca099c2`）因加入多平台自带 Key 而恢复设置面板——UI 有过反复，最终形态是「默认零配置 + 可选高级设置」。
- 修复 `e9227c9`：英文页此前因未导入 `currentLang` 总是退回中文预制答案。
- 对读者没有破坏性变更：所有新路径都在预制答案之上叠加。

## 数据与隐私影响

读者问题与局面上下文会发送给生效的 AI 平台（HTTPS）。无其他遥测。详见[隐私说明](../privacy.md)。

## 性能影响

每次提问一次网络往返（超时 15 秒）；免费模型偶发限流（实测约 1/4 概率空回答或 429），由重试与降级链吸收。

## 当前限制

- 免费模型无 SLA，高峰期可能整体降级到预制答案。
- 内嵌 Key 是混淆而非加密（有意取舍，仅限免费模型；付费 Key 请勿内嵌）。
- 教练无法看到读者当前棋盘上的错误尝试（上下文只含正确路径的 FEN 进度）。
