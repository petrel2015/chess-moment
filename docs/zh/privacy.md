# 隐私说明

本文说明棋刻如何处理数据。先说结论：**阅读、走棋、预制答案全部在浏览器本地完成，不经过任何服务器**；唯一的例外是你主动使用 AI 教练时，问题文本会发送给你所使用的 AI 平台。

## 不收集的东西

- 无账号系统：不需要注册、登录。
- 无分析统计：不接入任何 Analytics（无 Google Analytics、无埋点）。
- 无 Cookie：站点不使用 Cookie。
- 无服务端：GitHub Pages 只静态托管文件，站点没有自有后端，也不存在数据库。

## 保存在浏览器本地的数据（localStorage）

| 键 | 内容 | 清除方式 |
|----|------|----------|
| `chessMomentLang` | 语言偏好（zh/en） | 清除站点数据，或切换语言覆盖 |
| `chessCoachProvider` | 你选择的 AI 平台（若配置过） | 「AI 设置」里清空保存 |
| `chessCoachApiKey` | 你填写的 AI API Key（若配置过） | 「AI 设置」里清空保存 |

这些数据只存在于你的浏览器，站点无法（也不会）读取上传。

## 什么时候有数据离开浏览器

只有一种情况：**你主动点击「问教练」**。此时会通过 HTTPS 向当前生效的 AI 平台发送：

- 你输入的问题文本；
- 课程上下文：题目标题、目标、起始/当前局面 FEN、进度步数。

接收方按优先级可能是：

1. 你在「AI 设置」里配置的平台（OpenRouter / DeepSeek / 智谱 GLM），使用你自己的 Key；
2. 站点内嵌的 OpenRouter Key（免费模型）；
3. （若维护者配置了 Worker）维护者部署的 Cloudflare Worker 代理；
4. （实验路径）第三方免费中转（Pollinations）。

除此之外，任何操作都不会把数据发到站点之外。关闭/降级到预制答案时，问题文本也不会被发送。

## 站点默认内嵌 Key 的说明

站点在 `assets/coach-ai.mjs` 内嵌了一个经混淆（XOR + Base64）的 OpenRouter Key，只用于免费模型。它对任何有能力阅读前端源码的人都是可还原的——这是文档化的、有意为之的取舍，风险仅限于免费额度被他人消耗。你随时可以在「AI 设置」里用自带 Key 覆盖它。

## 用户主动触发的外部动作

- **反馈问题**：点按钮会打开你本地的邮件客户端并预填课程与局面信息，由你确认后才发送。
- **赞赏**：打开支付宝/微信的外部链接或二维码，由你确认后才继续。

这两项都不会自动发生。

## 第三方静态资源

站点不加载任何第三方统计、字体或 CDN 资源；棋子图片、样式、脚本全部自托管在 GitHub Pages。
