# 故障排查

## 网站打开异常

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 页面白屏、棋盘不出现 | 浏览器禁用了 JavaScript，或使用了非常老旧的浏览器 | 棋盘与挑战完全依赖 JS（ES Modules），请换现代浏览器 |
| 页面在中文/英文间来回跳转 | localStorage 语言偏好与手动地址栏输入冲突 | 点页头语言按钮切换一次，偏好会被重置 |
| 样式错乱 | 部署正在进行的缓存窗口 | 强制刷新（Cmd/Ctrl+Shift+R）；Pages 部署完成后数分钟内生效 |
| iPhone 添加主屏后图标/名称不对 | 主屏缓存 | 删除主屏图标重新添加 |

## 挑战交互

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 点棋子没有反应 | 点到了对方棋子或空格 | 先点白棋（你的棋子），再点高亮的目标格 |
| 走子显示红色反馈 | 该步不是本题正解（或非法走法） | 红色反馈附有一句解释；按提示再试，或点「给一点提示」 |
| 走对了但进度不动 | 命中了「合理但非最优」候选着（琥珀色讲解） | 候选着不计入进度，继续寻找正解 |
| 状态一直停在「对手正在回应……」 | 极罕见的对手回应异常（已被防御逻辑覆盖） | 点「重新挑战」；若复现请用「反馈问题」报告 |

## AI 教练

| 现象 | 原因 | 处理 |
|------|------|------|
| 秒回「预设参考」 | 所有 AI 路径都不可用（免费模型限流/网络受限），或浏览器拦截了第三方请求 | 稍后重试；或在「AI 设置」里配置自己的 OpenRouter/DeepSeek/GLM Key |
| 回答是英文（或中文）但页面是另一种语言 | 教练语言跟随页面语言 | 确认页头当前语言；切换语言后教练同步切换 |
| 长时间无响应后降级 | AI 平台超时（前端 15 秒超时） | 网络恢复后重试；免费模型偶发拥堵属正常 |
| 报错包含 429 / rate limit | 免费模型限流（实测偶发，约 1/4 概率空回答或限流） | 前端已自动重试并降级换模型；仍失败会退回预制答案 |
| 401 / Invalid key | 「AI 设置」里填的 Key 无效 | 检查 Key 是否复制完整、是否属于所选平台；清空保存可恢复站点默认 |
| CORS 报错 | 个别网络环境（企业代理/广告拦截）拦截了 AI 平台域名 | 换网络或配置自带 Key 的平台并放行对应域名 |

## 内容作者 / 维护者

| 现象 | 原因 | 处理 |
|------|------|------|
| `npm test` 报 `invalid move` | 走法不是 UCI 格式（升变要 5 字符，易位写王） | 按报错文件修正；格式见[开发指南](./development.md#课程-json-结构) |
| 报 `对手回应 ... 不合法` | `opponent` 写的走法在前一步之后的局面不合法 | 重新推演局面；校验器会给出具体走法 |
| 报 `odds ... do not sum to 100` | 某步胜算三项之和不是 100 | 归一化 odds 数组 |
| 报 `suggestion ... has no answer` | 快捷问题的 `key` 在 `quick` 里没有对应答案 | 补答案或改 key |
| 报 `duplicate slug` / 先修死链 | slug 重复或 `prerequisites` 指向不存在的课程 | 修正 slug 或先修列表 |
| 首页不是新课程 | 首页按「今天」的月日匹配 `publishedAt` | 今天未匹配时展示最近一期属预期；测试可用 `CHESS_HOME_DATE` 固定日期 |

以上都排除后，欢迎[提 Issue](https://github.com/petrel2015/chess-moment/issues) 或用页面「反馈问题」按钮，附上页面自动生成的局面报告。
